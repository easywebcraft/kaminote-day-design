### 案Cは 2026-08-23 に作り直した（白い帯のヘッダーと、弧で切った写真）

**保育園サイトの案Cを作り直したのに合わせて、こちらも同じ骨格にした**（ユーザー指示
「保育園案Cを放課後デイの案Cにも適用して」）。もとの「縦書きと全画面写真」は廃止。

- 白い帯のヘッダー。下端を**スカラップ（半円の連なり）**で切って写真にかぶせる
- ロゴは左、メニューは右。項目のあいだに小さなきらきら。右端に**破線の丸い採用バッジ**
- 写真は帯の下に全幅で敷き、**下端を大きな弧**で切って薄い緑の面へつなぐ
- 見出しは**写真の右下に横書き**、下に破線を1本ずつ（上は黄・下は白）
- **ヘッダーが白い帯になったので、実ロゴのマークをここに置けるようになった**
  （以前は「写真の上なので置けない」だったが、その前提が変わった）

**かぶせは保育園の案Cより濃い。** あちらの写真（積み木）は色が沈んでいるが、こちらは
クレヨンで明るい色が画面いっぱいなので、同じ数値だと見出しの1行目が黄色い面に負けて
読めなくなる。**かぶせは写真ごとに振り直すこと。**

**`.brand` を `flex:none` にすると縮まず、390px でハンバーガーを押し出して横あふれになった**
（`scrollWidth 433`）。`flex:0 1 auto` にして、長い社名は corp の省略記号で吸収させる。
**保育園の案Cも同じ書き方だったので合わせて直した**（あちらは社名が短くたまたま収まっていただけ）。

### （履歴）案Cは「寄り」と「暗いかぶせ」でAから離す（2026-08-20）

案Cは一時期「白文字をやめ、濃い文字に反転」してあった。もとの白い縦書き＋暗い
かぶせでは、白い紙が主のこの写真は `.66` まで沈めないと読めず「暗い印象を受ける」
という指摘があったため。ところが反転した結果、今度は**案Aと案Cが見分けられなく
なった**（同じ写真・どちらも白く飛ばす・どちらも濃い文字・見出しはどちらも明朝）。

そこで案Cを振り直した。**写真を寄せたことで、白文字に戻しても濁らなくなった**
のが要点。引きの構図では画面の大半が白い紙で、暗くすると全体が灰色に沈んだが、
寄せてクレヨンで埋まった画面は、沈めると深い色になる。**「暗くすると濁る」は
写真そのものの性質ではなく、構図の問題だった。**

- **写真を大きく寄せる。** `.hero-bg img` に `--z`（PC 1.55 / スマホ 1.2）を持たせ
  `transform:scale(var(--z))`。案A＝引き、案C＝寄りで第一印象を分ける。
  **`--z` を変えたら `zoomOut` キーフレームも合わせること**（`to` を `transform:none`
  にすると、動きの終わりで引きの構図に戻ってしまう。数値を書かず `var(--z)` を参照している）。
- **白いかぶせをやめ、暗いかぶせに戻す。** 白を全面にかけると案Aの「淡く飛ばした写真」と
  同じ絵になる。上下をやや濃くしているのは、ロゴ・メニューとボタンが乗るため。
- **縦書き・ロゴ・メニュー・コピーライトは白文字**、影は黒側に出す（保育園の案Cと同じ）。
- **かぶせは2回下げて `.36/.22/.2/.32` に落ち着いた。** `.54〜` では「暗すぎる」、
  `.44〜` でもまだ暗いという指摘。**薄くしたぶんは文字のまわりのにじみ影で稼ぐ**
  （`text-shadow` を2枚重ね＝近い距離の濃いものと、広く薄いもの。縦書き・添え文・
  メニュー・ロゴの4か所に入れてある）。**縁の出る帯を置かずに局所のコントラストだけ
  上げられる**のが要点。これより薄くすると、写真下半分の白い紙のところで白文字が
  消えるので、そこから先は文字色か写真を変える話になる。

**白い短冊（`.vband`）は試したが取りやめた。** 写真の色を残したまま濃い文字を読ませる
ために、白い帯を敷いてその上に縦書きを置く案を一度作った。読みやすさは解決するが、
**写真の上に四角い紙が浮いて見える**（貼り紙に見える）という指摘で不採用。
角丸や透明度では消えない、構造的な違和感なので**同じ手を再提案しないこと**。

### （履歴）2つの事業所のロゴ帯 ― 3案とも廃止した

外した理由はユーザーの言葉で「**あとの紹介ででてくるため**」＝

トップで先に見せると同じものを2回出すことになる。**この帯を復活させないこと。**

ロゴはいまも**ヘッダーのマーク（`logo-mark.png`・文字を消した絵柄だけ）**と
**「2つの事業所」の節（`.office-logo`）**の2か所に出ている。

**KIDSだけを大きく出さないこと。** このサイトは2事業所共通のサイトなので、
片方だけをトップに出すともう片方が従属して見える。ヘッダーのマークに実ロゴを
入れる案も検討したが、520×327の横長をヘッダーの高さ（46px）に収めると幅73px
まで縮み、顔の細い線画がつぶれるので採らなかった。

**ロゴPNGの背景は透過ではなく「ほぼ白（#fdfdfd）の半透明」だった。**
そのまま白地に置くと、周囲の #ffffff との差（3段）で四角い縁がうっすら出る。
`mix-blend-mode:multiply` では消えない（不透明な白ではなく半透明の白なので、
白地に重ねても 253 のまま）。**白に近く色みのない画素を完全な透明に置き換えて解決した**
（`min(r,g,b) >= 246` かつ `max-min <= 6`。元の画像は git の履歴から戻せる）。
判断は目視ではなく**スクリーンショットの画素値を測って**確認すること。

### ヘッダーのマークも実ロゴにした（案A・案B）

**2枚のロゴは文字以外の絵柄が完全に同一**なので、`img/logo-mark.png` ＝
**ロゴから文字（かみのて／KIDS・SMILE）を消して絵だけ残したもの**を作り、
ヘッダーのマークに使っている。これならKIDSにもSMILEにも寄らず、隣に置く
テキスト「かみのてKIDS・SMILE」と文字が重複しない。

- 文字は手の内側にあるので、**横一発の切り出しでは分けられない**。
  上（y<=105）は手が x<130 と x>400 にしか無いので広く消せるが、
  その下は手の親指と手のひらの縁が内側に入るので文字幅（x=174〜346）だけに絞る。
  最初この二段構えにせず消したら「か」と「て」がはみ出して残った。
- 横長（516×276）なので **`height` で指定する**（`width` だと縦に潰れる）。PC 52px／スマホ 38px。
- **ナビを畳む幅を 1080px → 1140px に上げた。** マークが横に広がったぶんブランド側が
  太り、1081px で「採用情報」がCTAに重なっていた。**`scrollWidth` には出ない崩れ。**
- **フッターの仮マークは削除した**（名前だけにした）。フッターは濃い地色で、
  透けたハートに地色が抜けるため実ロゴを置けず、仮マークを残すとヘッダーと食い違う。

**2026-08-23、案Cのヘッダーにも置いた。** 作り直して白い帯のヘッダーになり、
写真の上ではなくなったため。**「案Cには置けない」という以前の判断は、写真の上に
浮かせていたときの話**（顔の線と手のひらの透けたハートに写真が抜けて読めなかった）。
ヒーロー直下の白い帯（`.logos`）の2枚も、そのまま残してある。

2サイト案なので、KIDSとSMILEは別サイトではなく**1サイト内の2事業所**として扱う。
提案書のワイヤーにあった「※A案ではこの枠が『事業所のご案内』に変わります」は
A案（3サイト案）の話なので、B案であるここでは「2つの事業所」枠が正しい。

## デザインの意図

**イメージカラーはパステルグリーン（顧客の要望）。**
保育園サイトと同じ設計言語（Zen Maru Gothic ＋ Baloo 2、全面背景のヒーロー、
波型の区切り、ピル型ボタン、スクロールで出る演出）を使い、**色だけを振り分けている。**
CTAのオレンジは2サイト共通で、同じグループに見せるための共通言語。

- `--pg` #8ecfa5（面）／ `--pg-dark` #4e9c72（文字）／ `--pg-deep` #3d7d5b（濃い面）
- **薄いパステルグリーンを文字色に使わないこと。**読めなくなる。文字は `--pg-dark` 以上を使う。

**ヒーローに絵文字は入れない**（保育園サイトと同じ方針）。
セクションラベルの絵文字は使っている。

### 保育園サイトとの色のかぶり（解消済み）

かつて保育園サイトの主色がミント（#7fc6a0）で、**このパステルグリーンとほぼ同じ**
だったため、2サイトを並べると見分けがつかなかった。顧客要望で色が決まっているのは
放デイ側なので、動かしたのは保育園サイト。アプリコットを経て、
**2026-08-20 にパステルブルー（`#5fa8cc` / 薄い面 `#dcedf8`）に変更**して決着。

**CTAのオレンジは2サイト共通のまま。** 保育園＝パステルブルー＋オレンジ、
放デイ＝パステルグリーン＋オレンジで、配色の考え方がそろっている。
**放デイ側の主色は顧客要望なので動かさないこと。**
